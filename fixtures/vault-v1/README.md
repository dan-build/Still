# Golden v1 vault

A vault generated once by `scripts/generate-golden-vault.mts`, using the app's own `app/lib/crypto.ts` (both are in the git history; they were removed once the Rust core became the reference). Everything in it is dummy data, and the password is test-only.

- `vault.json` holds the five localStorage keys and their string values, exactly as the app stores them.
- `expected.json` holds the password and every expected plaintext, keyed by Lens id and item id.
- `vectors.json` holds fixed-input vectors: Argon2id outputs, key blobs, `crypto_kdf` subkeys and item blobs, built from fixed keys, nonces, salts and subkey ids. It was generated by `scripts/generate-crypto-vectors.mts` calling libsodium directly (also in the git history), and the output is deterministic. Any implementation must reproduce these bytes exactly.

The fixture pins the v1 encrypted format. Every implementation must decrypt it. The JS code did until it was retired; the Rust core does in `crates/still-core/tests/golden_v1.rs` and `vectors_v1.rs`.

**Never regenerate or edit these files to make a test pass.** If a test fails, the code has broken compatibility with existing vaults. Adding a new fixture for a new format version is fine, but this one stays as it is.
